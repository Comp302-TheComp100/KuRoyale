# Functional Requirements Summary

The KuRoyale system provides a comprehensive single-player real-time strategy experience where players manage decks, design arenas, and battle an AI opponent. The system enforces core game rules including an 8-card deck limit selected from a 28-card library, and validates custom arena layouts with specific tower placements. During gameplay, the system manages real-time interactions such as elixir resource generation, card deployment validation, automatic unit pathfinding and combat calculation, and victory condition checks based on tower destruction or time limits. Additionally, the system ensures data persistence by allowing players to seamlessly save and reload active match states, preserving all game progress including unit positions and resources.
